## 知识点 1：一份报错长什么样

新手看到一大片红字容易慌，其实报错是 Python 在**告诉你哪里出了问题**。我们拆开看：

```python
age = input("How old are you? ")
print(age + 1)
```

运行后输入 `18`：

```
Traceback (most recent call last):
  File "/home/you/learn-python/age.py", line 2, in <module>
    print(age + 1)
          ~~~~^~~
TypeError: can only concatenate str (not "int") to str
```

**从下往上读**：

| 位置 | 内容 | 意思 |
|---|---|---|
| 最后一行冒号前 | `TypeError` | **错误类型**：类型不对 |
| 最后一行冒号后 | `can only concatenate str (not "int") to str` | **具体说明**：字符串只能和字符串拼接，不能和整数拼接 |
| 倒数第 2～3 行 | `print(age + 1)` 和 `~~~~^~~` | **出错的代码**，波浪线指出具体位置 |
| `File ..., line 2` | 第 2 行 | **出错的文件和行号** |

所以这条报错的意思是：第 2 行，`age` 是字符串，不能直接 `+ 1`。修法你已经会了：`age = int(input(...))`。

> 读报错三步：**① 看最后一行的错误类型 → ② 看行号找到代码 → ③ 结合说明想原因。**

## 知识点 2：五种最常见的报错

### 1. `SyntaxError`：语法错误（代码写得不符合规则）

```python
if 5 > 3
    print("yes")
```
```
    if 5 > 3
            ^
SyntaxError: expected ':'
```
意思：这里应该有一个冒号。常见原因：少冒号、少括号、引号没闭合。

```python
print("Hello)
```
```
SyntaxError: unterminated string literal (detected at line 1)
```
意思：字符串没有结束（少了后面的引号）。

### 2. `IndentationError`：缩进错误

```python
if 5 > 3:
print("yes")
```
```
IndentationError: expected an indented block after 'if' statement on line 1
```
意思：`if` 下面应该有缩进的代码块。

### 3. `NameError`：名字没定义（通常是拼错了）

```python
name = "Tom"
print(nme)
```
```
NameError: name 'nme' is not defined. Did you mean: 'name'?
```
新版 Python 很贴心，还会猜你想写的是 `name`。

### 4. `TypeError`：类型不对

就是知识点 1 的例子：字符串和数字不能直接相加、比较大小。

### 5. `ValueError`：值不对

```python
age = int(input("Age: "))     # 用户输入了 abc
```
```
ValueError: invalid literal for int() with base 10: 'abc'
```
意思：`"abc"` 没法转成整数。类型对（是字符串），但内容不对。

> 💡 **一个重要规律**：`SyntaxError` 和 `IndentationError` 在程序**运行前**就会报出来，一行都不会执行；其他错误要**运行到那一行**才会出现。所以修好一个错误后，可能又冒出下一个，这很正常，一个一个来。

## 知识点 3：提前检查输入，避免 `ValueError`

用户不一定按你的要求输入。可以先用 `.isdigit()` 检查字符串是不是全是数字：

```python
text = input("How old are you? ").strip()

if text.isdigit():
    age = int(text)
    print(f"Next year you will be {age + 1}.")
else:
    print("Please enter a whole number.")
```

```python
print("18".isdigit())    # True
print("abc".isdigit())   # False
print("1.75".isdigit())  # False，小数点不是数字
```

> 先只处理正整数就好。负数、小数的检查方法以后再学。

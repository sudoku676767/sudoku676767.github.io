## 1. 程序是怎么跑起来的

**一句话**：程序就是一个文本文件，解释器从上往下一行行执行它；所有程序都是「输入 → 处理 → 输出」。

```
你写的 hello.py（文本）  →  python3（解释器）  →  执行结果
```

- **源代码**：`.py` 文件，就是普通文本，用任何编辑器都能打开。
- **解释器**：`python3` 这个程序，负责读你的代码并执行。
- **终端**：你给电脑下命令的地方。`python3 hello.py` 的意思是「让 python3 执行 hello.py」。
- **路径**：文件在电脑里的地址，如 `/home/sakura/learn-python/hello.py`。`~` 是你的主目录，`.` 是当前目录，`..` 是上一级目录。

**执行顺序**：默认从上往下；条件、循环、函数会改变这个顺序（后面讲）。

**输入 → 处理 → 输出**：再复杂的软件也是这个结构。
| 程序 | 输入 | 处理 | 输出 |
|---|---|---|---|
| BMI 计算器 | 身高体重 | 计算、判断 | 一行文字 |
| 微信 | 你打的字 | 加密、发送到服务器 | 对方手机上显示 |
| ChatGPT/Claude | 你的问题 | 模型计算 | 回答 |

> 🔍 读代码时先问：**它的输入是什么？输出是什么？** 中间的部分就是处理。

## 2. 数据：变量和类型

**一句话**：变量是给数据起的名字；每个数据都有类型，类型决定了它能做什么操作。

| 类型 | 例子 | 能做什么 |
|---|---|---|
| `int` 整数 | `18` | 加减乘除 |
| `float` 小数 | `1.75` | 加减乘除 |
| `str` 字符串 | `"Hello"` | 拼接、切片、查找 |
| `bool` 布尔 | `True` / `False` | 用于判断 |
| `None` 空值 | `None` | 表示「什么都没有」 |
| `list` 列表 | `[1, 2, 3]` | 存一串有顺序的数据 |
| `dict` 字典 | `{"name": "Tom"}` | 用名字查数据 |

**三个必须记住的点**：
1. `=` 是「赋值」：把右边的值放进左边的名字。`==` 才是「判断相等」。
2. `"18"` 和 `18` 是两种东西。外部来的数据（键盘输入、文件、网页）**几乎都是字符串**，计算前要转换：`int()`、`float()`、`str()`。
3. 类型不对是最常见的 bug 来源（第 3、4 天的 `555` 就是例子）。

▶
```python
print(type(18), type("18"), type(1.75), type(True), type(None))
print(int("18") + 1)
print(str(18) + "!")
```

## 3. 控制流：条件和循环

**一句话**：条件决定「做不做」，循环决定「做几次」。

### 条件（已学过）

```python
if score >= 90:
    print("A")
elif score >= 60:
    print("Pass")
else:
    print("Fail")
```

### 循环：`for` 和 `while`

`for` 用于「对每一个东西做一遍」：

▶
```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(f"I like {fruit}")

for i in range(3):      # range(3) 生成 0, 1, 2
    print(i)
```

`while` 用于「只要条件成立就一直做」：

▶
```python
count = 3
while count > 0:
    print(count)
    count = count - 1
print("Go!")
```

- `break`：立刻跳出循环
- `continue`：跳过这一轮，进入下一轮

▶
```python
for n in range(1, 10):
    if n % 2 == 0:
        continue        # 跳过偶数
    if n > 7:
        break           # 大于 7 就停
    print(n)            # 输出 1 3 5 7
```

> ⚠️ `while` 的条件如果永远成立，就是**死循环**，程序停不下来。终端里按 `Ctrl+C` 强制停止。

> 🔍 读循环时问：**它在对什么做循环？每一轮做了什么？什么时候停？**

## 4. 函数：把代码打包

**一句话**：函数是一段有名字、可重复使用的代码。给它输入（参数），它返回输出（返回值）。

▶
```python
def calculate_bmi(weight, height):
    """Return BMI rounded to 1 decimal place."""
    bmi = weight / height ** 2
    return round(bmi, 1)

result = calculate_bmi(68, 1.75)
print(result)                       # 22.2
print(calculate_bmi(50, 1.60))      # 19.5
```

拆开看：
- `def`：定义函数；`calculate_bmi` 是名字
- `weight, height`：**参数**，调用时传进来的值
- `"""..."""`：文档字符串，说明函数做什么
- `return`：**返回值**，把结果交回给调用它的地方
- `calculate_bmi(68, 1.75)`：**调用**函数

**为什么要用函数**：
1. 不重复写同样的代码
2. 给一段逻辑起个好名字，代码更好读
3. 可以单独测试

**`print` 和 `return` 的区别**（新手最常混淆）：
- `print` 是**显示给人看**，结果不能再用
- `return` 是**交给程序用**，可以存进变量、继续计算

**作用域**：函数里面创建的变量，函数外面看不到。

▶
```python
def greet(name="friend"):   # 参数可以有默认值
    message = f"Hello, {name}!"
    return message

print(greet("Tom"))
print(greet())
# print(message)   # 会报 NameError：message 只存在于函数内部
```

> 🔍 AI 写的代码大部分都是由函数组成的。读一个函数，先看三样：**名字、参数、返回值**。看懂这三样，往往不用看里面的细节就知道它在干什么。

## 5. 数据结构：列表和字典

**一句话**：列表按**顺序**存一串数据；字典按**名字（键）**存数据。现实中几乎所有数据都是这两者的组合。

### 列表 list

▶
```python
scores = [85, 92, 78]
scores.append(60)           # 在末尾添加
print(scores[0])            # 85，第一个
print(scores[-1])           # 60，最后一个
print(len(scores))          # 4
print(sum(scores) / len(scores))   # 平均分 78.75
print(sorted(scores))       # [60, 78, 85, 92]
```

### 字典 dict

▶
```python
student = {"name": "Tom", "age": 18, "city": "Beijing"}
print(student["name"])          # Tom
student["age"] = 19             # 修改
student["email"] = "tom@example.com"   # 添加
print(student.get("phone", "N/A"))    # 不存在时返回默认值
for key, value in student.items():
    print(f"{key}: {value}")
```

### 组合：列表里放字典（最常见的数据形状）

▶
```python
students = [
    {"name": "Tom", "score": 85},
    {"name": "Amy", "score": 92},
]
for s in students:
    print(f"{s['name']} got {s['score']}")

best = max(students, key=lambda s: s["score"])
print(f"Best: {best['name']}")
```

> `lambda s: s["score"]` 是一个**没有名字的小函数**，意思是「对每个 s，取它的 score」。AI 代码里很常见，认识就行。

> 🔍 以后你看到的接口数据、配置文件、数据库查询结果，基本都是「列表里套字典」。读代码时先搞清楚**数据长什么样**，代码就好懂一半。

## 6. 错误和调试

**一句话**：报错是 Python 在告诉你哪里出了问题；调试就是让程序把内部状态「说出来」。

**读报错**（第 3 天讲过）：从最后一行看错误类型 → 看行号 → 想原因。

| 错误 | 意思 |
|---|---|
| `SyntaxError` | 语法写错（少冒号、括号、引号） |
| `IndentationError` | 缩进错误 |
| `NameError` | 名字没定义或拼错 |
| `TypeError` | 类型不对（如字符串加数字） |
| `ValueError` | 值不对（如 `int("abc")`） |
| `KeyError` | 字典里没有这个键 |
| `IndexError` | 列表下标越界 |
| `FileNotFoundError` | 文件不存在 |
| `ModuleNotFoundError` | 没装这个库 |

**处理错误**：`try / except`，「试着做，出错了就怎样」。

▶
```python
text = "abc"
try:
    number = int(text)
    print(f"Got {number}")
except ValueError:
    print("That is not a number.")
```

**调试三板斧**：
1. **加 print**：在可疑的地方打印变量，看它的值和类型 `print(repr(x), type(x))`
2. **断点**：VS Code 里点行号左边设断点，按 F5 一步步执行，观察变量
3. **缩小范围**：把代码删到最少还能复现问题，问题在哪就清楚了

**最重要的认知**：**没报错 ≠ 程序是对的**。一定要拿具体的输入，去核对输出是不是你预期的。

## 7. 模块、包和环境

**一句话**：别人写好的代码打包成「库」，你 `import` 进来就能用，不用从零写。

```python
import random                   # 标准库：Python 自带
print(random.randint(1, 6))     # 掷骰子

from datetime import date
print(date.today())
```

- **标准库**：Python 自带的，直接 `import`（如 `random`、`json`、`datetime`、`pathlib`）
- **第三方库**：别人发布的，要先安装（如 `requests` 发网络请求、`pandas` 处理表格、`fastapi` 写网站后端）
- **pip**：安装第三方库的工具
- **虚拟环境 venv**：给每个项目一个独立的「库的房间」，避免项目之间互相干扰

在 Ubuntu 上的标准做法：
```bash
cd ~/my-project
python3 -m venv .venv          # 创建虚拟环境（只需一次）
source .venv/bin/activate      # 进入虚拟环境（每次打开终端都要）
pip install requests           # 安装库
pip freeze > requirements.txt  # 记录用了哪些库
deactivate                     # 退出虚拟环境
```

> Ubuntu 不允许直接往系统里 `pip install`（会报 `externally-managed-environment`），所以**一律先建虚拟环境**。

> 🔍 读别人项目时，先看 `requirements.txt` 或 `pyproject.toml`：它列出了项目依赖哪些库，你一眼就能知道这个项目大概在做什么。

## 8. 程序和外部世界：文件、JSON、网络、数据库

**一句话**：程序真正有用，是因为它能读写外部的数据。

### 文件

▶
```python
with open("notes.txt", "w") as f:       # "w" 写入（会覆盖）
    f.write("First line\n")
with open("notes.txt", "a") as f:       # "a" 追加
    f.write("Second line\n")
with open("notes.txt") as f:            # 默认 "r" 读取
    for line in f:
        print(line.strip())
```

`with` 的作用：用完自动关闭文件，不用操心。

### JSON：程序之间交换数据的通用格式

JSON 长得和 Python 的字典、列表几乎一样，可以直接互相转换：

▶
```python
import json

data = {"name": "Tom", "skills": ["Python", "Git"]}
text = json.dumps(data)                 # 字典 → JSON 字符串
print(text)
back = json.loads(text)                 # JSON 字符串 → 字典
print(back["skills"][0])                # Python
```

### 网络：HTTP 和 API

- **HTTP**：浏览器和服务器之间说话的规则。你打开网页 = 发一个请求，服务器回一个响应。
- **API**：一个专门给程序（而不是给人）用的网址，返回的通常是 JSON。天气、地图、大模型（如 Claude）都通过 API 提供服务。
- 常见请求方式：`GET` 获取数据，`POST` 提交数据。
- 状态码：`200` 成功，`404` 找不到，`401/403` 没权限，`500` 服务器出错。

```python
import requests                                     # 需要先 pip install requests
response = requests.get("https://api.github.com")   # 发 GET 请求
print(response.status_code)                         # 200
data = response.json()                              # JSON → 字典
```

### 数据库

- 数据多了、要长期保存、要多人同时用时，就不用文件，改用**数据库**。
- 最常见的是**关系型数据库**（SQLite、MySQL、PostgreSQL），数据存成一张张表格，用 **SQL** 语言查询：

```sql
SELECT name, score FROM students WHERE score >= 60 ORDER BY score DESC;
```

读作：从 students 表里，选出分数 ≥ 60 的学生的名字和分数，按分数从高到低排。

> 🔍 一个典型的网站/App 就是：**前端**（用户看到的页面）→ 通过 **API** 发请求 → **后端**（服务器上的程序）→ 读写**数据库** → 返回 **JSON** → 前端显示。这张图记住了，大部分项目你都能定位到「这段代码在哪一层」。

## 9. 类和对象

**一句话**：类是「模板」，对象是按模板造出来的「东西」；它把**数据**和**操作这些数据的函数**放在一起。

▶
```python
class Dog:
    def __init__(self, name, age):      # 创建对象时自动执行
        self.name = name                # 属性：对象的数据
        self.age = age

    def bark(self):                     # 方法：对象能做的事
        return f"{self.name} says woof!"

my_dog = Dog("Buddy", 3)                # 创建一个对象
print(my_dog.name)                      # Buddy
print(my_dog.bark())                    # Buddy says woof!
```

- `__init__`：初始化，创建对象时设置它的数据
- `self`：指「这个对象自己」
- `my_dog.name` 访问属性，`my_dog.bark()` 调用方法

其实你早就在用对象了：`"hello".upper()` 里，`"hello"` 是一个字符串对象，`upper` 是它的方法。

> 🔍 你暂时不需要自己设计类，但要能读懂。看到 `class` 时问：**它代表什么东西？存了哪些数据（`self.xxx`）？能做哪些事（方法）？**

## 10. 工程基础：Git、项目结构、测试

### Git：代码的「存档点」

- 每次 `commit` 就是存一个档，随时可以回到任何一个存档。
- **和 AI 协作时这是你的安全网**：AI 改坏了，一条命令退回去。

```bash
git init                        # 在项目文件夹里启用 Git（只需一次）
git add .                       # 把改动放进「待存档区」
git commit -m "Add BMI calculator"   # 存档，并写一句说明
git log --oneline               # 查看存档历史
git diff                        # 查看还没存档的改动（审查 AI 改了什么就靠它）
git checkout -- file.py         # 放弃对某个文件的改动
```

- **GitHub**：把存档放到网上，备份 + 分享 + 协作。

### 一个典型 Python 项目长这样

```
my-project/
├── README.md            # 项目说明：是什么、怎么运行
├── requirements.txt     # 依赖了哪些库
├── .gitignore           # 告诉 Git 哪些文件不要存档（如 .venv）
├── main.py              # 程序入口
├── app/                 # 主要代码
│   ├── models.py        # 数据长什么样
│   ├── services.py      # 核心逻辑
│   └── api.py           # 对外接口
└── tests/               # 测试
    └── test_services.py
```

> 🔍 拿到一个新项目，按这个顺序看：**README → requirements → 入口文件 → 核心逻辑**。

### 测试：用代码检查代码

▶
```python
def add(a, b):
    return a + b

assert add(2, 3) == 5        # 成立，什么都不发生
assert add(-1, 1) == 0
print("All tests passed!")
```

`assert` 的意思是「我断言这件事成立」，不成立就报错。正式项目里用 `pytest` 工具批量运行测试。

**测试对你特别重要**：你不一定写得出实现，但你能写出「输入是什么、应该输出什么」。**把测试交给 AI，让它写代码让测试通过**，这就是你指挥 AI 最可靠的方式（Kent Beck 的思路）。

## 11. 怎么读一段陌生代码（读 AI 代码的方法）

拿到一段代码，按这个顺序：

1. **先看整体**：有哪些函数/类？名字分别是什么？（名字起得好，光看名字就懂一半）
2. **找入口**：程序从哪里开始执行？（通常是文件最下面，或 `if __name__ == "__main__":` 下面）
3. **看数据**：输入是什么？中间的数据长什么样（列表？字典？）？输出是什么？
4. **跟一个例子走一遍**：拿一个具体输入，在脑子里（或用 print/断点）跟着代码走，看每一步变量变成什么
5. **看边界**：输入为空、为 0、为负数、格式不对时会怎样？
6. **最后才看细节**：某一行具体怎么写的，不懂就问 AI「这一行在做什么？」

**审查 AI 代码的检查清单**：
- [ ] 它做的是我要求的事吗？有没有多做或少做？
- [ ] 外部输入（用户输入、文件、网络）有没有做类型转换和检查？
- [ ] 每个 `if` 分支我都用例子走过一遍了吗？
- [ ] 有没有用到我不认识的库？它是做什么的？
- [ ] `git diff` 里有没有我没让它改的地方？
- [ ] 我能用自己的话把这段代码讲给别人听吗？

**`if __name__ == "__main__":` 是什么**：

```python
def main():
    print("Program starts here")

if __name__ == "__main__":
    main()
```

意思是：「只有直接运行这个文件时，才执行 `main()`；被别的文件 import 时不执行」。AI 写的 Python 程序几乎都有这一段，看到它就知道**入口在这里**。

## 12. 速查表和自测题

### 速查表

| 想做的事 | 写法 |
|---|---|
| 输出 | `print(f"Hi {name}")` |
| 输入 | `x = input("...")`（得到字符串） |
| 类型转换 | `int()` `float()` `str()` |
| 条件 | `if / elif / else`，`and / or / not` |
| 对每个元素做事 | `for x in items:` |
| 重复 N 次 | `for i in range(n):` |
| 条件成立就一直做 | `while cond:` |
| 定义函数 | `def name(params): ... return value` |
| 列表 | `[]`，`.append()`，`[0]`，`len()` |
| 字典 | `{}`，`d["key"]`，`d.get("key")`，`.items()` |
| 处理错误 | `try: ... except XxxError: ...` |
| 用别人的库 | `import xxx`，`pip install xxx`（先建 venv） |
| 读写文件 | `with open("f.txt") as f:` |
| JSON | `json.loads()` / `json.dumps()` |
| 类 | `class X: def __init__(self, ...):` |
| 存档 | `git add . && git commit -m "..."` |
| 测试 | `assert f(x) == expected` |

```python
# 5
```

```python
# 6
```
